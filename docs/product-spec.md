# CoinLens

Independent evidence-based Solana research dashboard inspired by Ask The Hound's public product interface.

## Milestones
- Responsive overview, case archive and detailed reports
- Read-only token metadata and market data
- Public holder distribution, wallet history and token similarity
- Evidence-backed summaries with clear uncertainty and sources
- Live charts, alerts, profiles and rewards accounting

Never store private keys or sign transactions. Keep demo data clearly labeled. Use original branding, assets and implementation.
